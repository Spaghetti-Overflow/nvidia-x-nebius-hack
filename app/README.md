# Executable product boundary

All future executable product material lives under `app/`: source, tests, scripts, evaluations, and generated runtime artifacts. Canonical project knowledge remains in [`../docs/`](../docs/README.md); research and hypotheses do not become dependencies by implication.

The product, language, package manager, framework, runtime, and architecture are **undecided**, so this directory intentionally contains no application scaffold.

Before implementation, read [`../docs/product.md`](../docs/product.md), [`../docs/architecture.md`](../docs/architecture.md), and relevant decisions. Evaluation conventions are in [`evals/README.md`](evals/README.md).
