# nvidia-x-nebius-hack

Shared operating workspace for a four-person team entering the Nebius x NVIDIA Global AI Hackathon 2026. The product is **not selected**. Current exploration is centered on the Coding and Agentic Engineering track, especially agent runtimes, context, execution, verification, and developer tooling.

## Start here

1. Read [`AGENTS.md`](AGENTS.md) for repository routing and working rules.
2. Read [`docs/hackathon.md`](docs/hackathon.md) for binding constraints.
3. Use [`research/`](research/README.md) for evidence and [`ideas/`](ideas/README.md) for hypotheses.
4. Treat [`docs/product.md`](docs/product.md) and [`docs/architecture.md`](docs/architecture.md) as undecided until the team explicitly accepts a direction.

| Path | Meaning |
|---|---|
| `docs/` | Canonical knowledge the team accepts |
| `research/` | External evidence and analysis; not decisions |
| `ideas/` | Candidate problems and product hypotheses |
| `app/` | Future executable product, tests, and evaluations |

Implementation begins only after the product and enough architecture are decided.
