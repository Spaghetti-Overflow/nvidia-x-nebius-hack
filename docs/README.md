# Canonical project knowledge

`docs/` contains constraints, definitions, and decisions the team currently accepts. It is authoritative for the project, unlike external evidence in [`research/`](../research/README.md) or hypotheses in [`ideas/`](../ideas/README.md).

Unknowns stay explicit. Evidence becomes project truth only through team acceptance and, for material choices, an [`ADR`](decisions/README.md).

## Workflows

- [`validate-idea-with-chatgpt.md`](validate-idea-with-chatgpt.md) — fast, read-only gate against the canonical hackathon requirements and idea criteria
- [`research-with-chatgpt.md`](research-with-chatgpt.md) — full, source-driven research workflow for a personal idea from a regular ChatGPT conversation
